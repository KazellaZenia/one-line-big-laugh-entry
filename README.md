One funny line, 200 characters or fewer, that lands entirely on its own. A smart speaker asked for something relaxing answers with the least relaxing thing it knows.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
